# Nandita Santra — Digital Marketing Specialist Portfolio

A modern, high-performance portfolio website built for **Nandita Santra** (Digital Marketing Specialist — SEO, Social Strategy & Content).

---

## ⚡ Tech Stack & Architecture

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org) + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Utility Palette (Porcelain, Onyx, Antique White)
- **Smooth Scroll**: [Lenis Smooth Scroll](https://lenis.darkroom.engineering) at 60fps
- **Animations**: Framer Motion + GSAP ScrollTrigger
- **Typography**: Plus Jakarta Sans (Google Font)
- **Contact API**: Next.js App Router API Endpoint (`/api/contact`)

---

## 🚀 Getting Started

First, install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

---

## 📦 Production Build

To test or build the optimized production bundle:

```bash
npm run build
npm run start
```

---

## 📁 Key Features

- **Hero Section**: Asymmetric editorial layout with parallax motion & high-impact display typography.
- **About Section**: Portrait photo display with narrative philosophy, key capabilities, and academic credentials.
- **Experience Timeline**: Structured work history across lifestyle, food, and e-commerce clients.
- **Services Showcase**: Detailed Breakdown of SEO, Social Strategy, Meta Ads, and Content Services.
- **Brand Collaborations**: Interactive horizontal-scroll track featuring real brand work.
- **4-Step Growth Process**: Step-by-step strategy workflow breakdown.
- **Dual-Recipient Contact Form**: Form submissions routed directly to `nanditasantra924@gmail.com` and test recipient.
